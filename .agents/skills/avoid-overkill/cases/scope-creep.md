# Scope creep

**Situation:** The user asks to run one experiment and save its result.

**Overreaction:** Also redesign the launcher, introduce a config framework, rewrite the paper, update adjacent reports, and create future extension points.

**General response:** Run the requested experiment, preserve its artifact and evidence, report the result, and stop. Propose adjacent work separately if it becomes necessary.

**Rule:** A useful neighboring problem is still outside scope until it affects the requested outcome.
